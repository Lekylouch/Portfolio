# Portfolio — Sylvestre Ibara

Site web personnel statique (HTML/CSS via Tailwind CDN), hébergé sur **GitHub Pages**.

## Objectif

Présenter mon profil, mon parcours et mes projets (BUT GEII, stages, réalisations techniques) à destination de recruteurs, tuteurs et collaborateurs potentiels.

## Pages

| Fichier | Contenu |
|---|---|
| `index.html` | Page d'accueil — profil, présentation générale |
| `profil.html` | Profil détaillé |
| `formations.html` | Parcours de formation |
| `competences.html` | Compétences techniques |
| `pro.html` | Expériences professionnelles |
| `projects.html` | Liste des projets réalisés |
| `butgeii.html` | Détail du BUT GEII |
| `bilan.html` | Bilan / synthèse |
| `viewer.html` | Visualisation de documents (CV, preuves) |

Le dossier `preuves/` contient les justificatifs (certificats, attestations...) et `img/` les images utilisées sur le site.

## Déploiement

Le site est servi directement depuis ce dépôt via GitHub Pages (fichier `.nojekyll` présent pour désactiver le traitement Jekyll). Toute modification poussée sur la branche par défaut est publiée automatiquement.
